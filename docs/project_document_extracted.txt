ซอฟต์แวร์ที่ใช้ในการพัฒนาระบบ
ภาษาที่ใช้ในการพัฒนาระบบคือ ภาษา TypeScript โดยใช้ Bun NextJs Framework สำหรับพัฒนาในส่วนของการแสดงผลและติดต่อผู้ใช้ และ ใช้ Bun Elysiajs Framework สำหรับพัฒนาในส่วนของ API Server 
ฐานข้อมูลที่ใช้งานการจัดเก็บข้อมูล คือ MySQL
เทคโนโลยีสำหรับพัฒนาการทำงานแบบเรียลไทม์ คือ WebSockets / SSE
เทคโนโลยีด้านความปลอดภัยพัฒนาโดยใช้ JOSE (JWT), SHA-256 + Salt, Elysia Rate Limit
ระบบงานและขอบเขตงาน
1. ระบบสมัครสมาชิกสำหรับลูกค้าและเข้าสู่ระบบ
2. ระบบแสดงรายการอาหาร
3. ระบบจัดการรายการอาหารและเมนู
4. ระบบตะกร้าสินค้า
5. ระบบสั่งซื้อ
6. ระบบชำระเงิน
7. ระบบคิวออเดอร์
8. ระบบจัดการสถานะคำสั่งซื้อ
9. ระบบการแจ้งเตือนแบบเรียลไทม์พร้อมแจ้งเตือนเสียง
10. ระบบรายงานยอดขาย
11. ระบบแนะนำวิธีใช้งานสำหรับลูกค้า
กลุ่มผู้ใช้งานของระบบ
1. ลูกค้า
- ลูกค้าสามารถสมัครสมาชิกและเข้าสู่ระบบด้วยชื่อเล่นและหมายเลขโทรศัพท์ 
- สามารถดูรายการอาหารและรายละเอียดของเมนู ตรวจสอบราคา รูปภาพ หมวดหมู่อาหาร และสถานะความพร้อมของอาหารแบบเรียลไทม์ 
- สามารถเลือกอาหารและเพิ่มรายการลงในตะกร้าสินค้า 
- สามารถตรวจสอบและยืนยันคำสั่งซื้อ 
- สามารถชำระเงินออนไลน์ได้ 
 - สามารถรับหมายเลขคิวและตรวจสอบลำดับคิวของตนเอง 
- สามารถติดตามสถานะคำสั่งซื้อแบบเรียลไทม์ ได้แก่ ยืนยันคำสั่งซื้อ กำลังจัดทำ และเสร็จสิ้นพร้อมรับสินค้า รวมถึงสามารถรับการแจ้งเตือนเมื่อสถานะคำสั่งซื้อมีการเปลี่ยนแปลง
2. ร้านค้า
- ร้านค้าสามารถเข้าสู่ระบบจัดการร้านค้าและตรวจสอบคำสั่งซื้อที่เข้ามาในระบบ - สามารถดูรายละเอียดรายการอาหารและคำสั่งซื้อของลูกค้า 
- สามารถยืนยันหรือยกเลิกคำสั่งซื้อ 
- สามารถเปลี่ยนสถานะคำสั่งซื้อจากยืนยันคำสั่งซื้อเป็นกำลังจัดทำ และเปลี่ยนเป็นเสร็จสิ้นพร้อมรับสินค้า 
- สามารถจัดการลำดับคิวของคำสั่งซื้อ 
- สามารถเพิ่ม แก้ไข และจัดการข้อมูลรายการอาหาร หมวดหมู่ ราคา และสถานะความพร้อมของอาหารหรือวัตถุดิบ 
- สามารถรับการแจ้งเตือนและเสียงแจ้งเตือนเมื่อมีคำสั่งซื้อใหม่เข้ามา 
- สามารถตรวจสอบยอดขายและรายได้ของร้านค้า 
- สามารถส่งข้อมูลการเปลี่ยนแปลงสถานะคำสั่งซื้อไปยังหน้าจอของลูกค้าแบบเรียลไทม์
